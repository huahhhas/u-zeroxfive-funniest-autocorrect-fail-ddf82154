# Funniest Autocorrect Fail

One line, under 200 characters, that reads as a hilarious autocorrect fail — entered in the [make.fun bounty](https://make.fun/bounty/u-zeroxfive-funniest-autocorrect-fail-ddf82154).

## The line

> I texted my landlord 'the sink is leaking' — autocorrect sent 'the sink is leaving' and he replied 'good riddance, it never paid rent.'

Autocorrect swaps one real word for another — *leaking* becomes *leaving* — and the landlord answers as if the sink were a tenant moving out.

## Run it

```sh
python3 main.py
```

`main.py` prints the line; `entry.txt` holds exactly that output.
